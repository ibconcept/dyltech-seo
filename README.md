# Dyltech Computers - SEO Optimization

This repository is a dedicated environment for SEO optimization. 

## Task Overview
Your goal is to improve the SEO performance of Dyltech Computers without touching the core business logic.

## Key Files
- `public/`: Contains icons, logos, `robots.txt`, and `sitemap.xml`.
- `index.html`: Base HTML structure and static meta tags.
- `src/components/SEO.tsx`: React component managing dynamic meta tags and JSON-LD Schema.

## Getting Started
1. Install dependencies:
   ```bash
   npm install
   ```
2. Start the development server:
   ```bash
   npm run dev
   ```
3. Open the browser to see the SEO preview page.
